# HELP DESK SYSTEM

## Objetivo

Sistema web para gerenciamento de chamados técnicos.

## Stack

Backend:
- Node.js
- Express
- SQLite
- JWT

Frontend:
- React
- Vite
- Context API

## Funcionalidades implementadas

- Login
- Autenticação
- Controle de permissões
- Cadastro de usuários
- Cadastro de categorias
- Abertura de chamados
- Comentários
- Dashboard
- Gerenciamento de usuários

## Arquitetura

Backend:
Controllers
Routes
Middlewares
Utils

Frontend:
Pages
Components
Contexts
Services
